# 2026-06-10

## Spin 组件重构优化

全面重构 `packages/ui/src/spin/`，结合 Web 动画设计最佳实践：

### 改动内容
- **SVG 动画**：从单圆环旋转升级为「底层轨道圆 + 顶层 75% 追逐弧线」，使用 `strokeDasharray` + CSS `rotate` 动画
- **GPU 加速**：添加 `will-change: transform` 到 spinner SVG
- **无障碍**：完整 `prefers-reduced-motion` 降级（opacity 替代动画）；`role="status"` + `aria-busy` 标记
- **新 props**：`delay`（防快速闪烁）、`variant`（`'default' | 'dot'`）
- **CSS 优化**：覆盖层入场使用 ease-out；内容模糊使用 ease-out 加速恢复；移除冗余尺寸类
- **新变体**：`variant="dot"` — 三点弹跳动画（stagger 0.2s interval）
- **内联 SpinnerSvg**：不再依赖 `@aura/icons/SpinIcon`，JSX 内直接生成 SVG
- **测试**：从 9 个扩展到 24 个（覆盖 delay、variant、ARIA、unmount cleanup）

### 技术决策
- CSS keyframes 用于恒速循环动画（不需要 Framer Motion）
- 弧线长度 = circumference × 0.75（经典 spinner 比例）
- strokeWidth 根据尺寸动态计算：≤16px → 2.5px, ≤24px → 2.5px, 其余 → 3px
