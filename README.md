# Aura

基于 React 18 + dumi2 的现代化 AI 友好组件库，采用 monorepo 架构。

## 包结构

| 包名 | 说明 |
|------|------|
| `@aura/ui` | UI 组件库 |
| `@aura/request` | Fetch 请求封装 |
| `@aura/shared` | 共享工具函数 |

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动文档开发服务器
pnpm dev
```

## 技术栈

- **构建工具**: dumi2 (基于 Umi 4)
- **UI 框架**: React 18
- **语言**: TypeScript
- **包管理**: pnpm workspaces
