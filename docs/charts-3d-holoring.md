# HoloRing

科技环装饰层：多层全息环反向旋转，中央可选核心光点。ParticleField 的兄弟组件——同一个定位：纯装饰、aria-hidden、pointer-events 关闭、WebGL 不可用时降级。

## API

| 属性        | 说明                           | 类型       | 默认值             |
| ----------- | ------------------------------ | ---------- | ------------------ |
| layers      | 环层数（1~3）                  | `number`   | `2`                |
| colors      | 环色数组（按层循环取用）       | `string[]` | 天蓝 / 电光紫 / 青 |
| speed       | 旋转速度倍率，0 = 静止         | `number`   | `1`                |
| coreOpacity | 中央核心光点透明度，0 = 不显示 | `number`   | `0.5`              |
| tube        | 环管粗细（世界单位）           | `number`   | `3.2`              |

## 设计说明

**反转旋转是机械感的关键**

相邻层以相反方向旋转（奇数层正向、偶数层反向），倾角各自错开——同向等速旋转看起来只是「转圈」，反向差速才有「全息装置在运转」的感觉。

**纯装饰的边界**

与 ParticleField 相同：aria-hidden 默认开启、pointer-events 关闭、DPR 上限 1.5、`prefers-reduced-motion` 静止、WebGL 不可用时降级为 CSS 圆环。装饰层的一切失败都不应该影响页面主体。

**使用建议**

适合作为标题背景、空态插画、登录页主视觉的底层元素。叠加内容时给装饰层 `opacity: 0.5~0.7`——全息环的存在感要「隐约可见」，抢了内容的焦点就是失败的装饰。
