## 构建要点

**深色的实现成本是零**

- 图表主题：`theme={darkTheme}`（库内置暗色主题，含坐标、网格、提示框配色）；
- 页面装饰：卡片背景、边框、文字色由页面自己写——这是页面的责任，不是图表的；
- 全局联动：外层容器设 `data-theme="dark"` 后，库内读取的 `--aura-*` CSS 变量在子树自动切暗色，图表内部无需感知。

**布局**

经典 12 列网格，卡片用 CSS Grid 铺排；每张卡都是 `flex` 纵向布局，图表 `height` 固定、宽度自适应容器。1920 设计稿下等比放大用 `transform: scale` 方案，本示例为保证文档内可读未做缩放。

**数据策略**

- 示例数据全部**确定性生成**（正弦叠加 + 尖峰），刷新不变、可录屏；
- 真实业务建议：原始数据按分钟 / 小时**预聚合**后再交给图表——十万个原始点聚合后通常只有几百个有信息量的点；
- 点数多的图开 `dataZoom` + 默认 LTTB 采样，点数特别大时留意 Canvas 自动切换阈值。

**交互与无障碍**

大屏不是只读的：每张图都有 tooltip、图例点选隐藏系列、K 线十字定位。隐藏数据表让读屏器也能读到每张图的数值——大屏的「看」与「读」应该同时可用。

## 与主题定制的关系

大屏用的 `darkTheme` 就是[主题定制](/charts-theme)里描述的暗色令牌集。想调整主色（比如换成监控蓝），给大屏容器覆盖 `--aura-primary-*` 变量即可，图表、tooltip、图例会一起变。
