# 色系卡

图表库的全部配色约定，分四个场景：2D 数据色板、大屏深色体系、3D 组件色带、装饰组件色。换肤或调整品牌色时以本页为准。

## ① 2D 数据色板

`DEFAULT_PALETTE`（12 色），多系列图表按序取色，单系列恒为品牌紫：

| #   | 色值      | 名称        |     | #   | 色值      | 名称   |
| --- | --------- | ----------- | --- | --- | --------- | ------ |
| 1   | `#7c3aed` | violet 主色 |     | 7   | `#14b8a6` | teal   |
| 2   | `#0ea5e9` | sky         |     | 8   | `#f97316` | orange |
| 3   | `#10b981` | emerald     |     | 9   | `#ec4899` | pink   |
| 4   | `#f59e0b` | amber       |     | 10  | `#6366f1` | indigo |
| 5   | `#ef4444` | red         |     | 11  | `#84cc16` | lime   |
| 6   | `#8b5cf6` | purple      |     | 12  | `#06b6d4` | cyan   |

整体替换用 `palette` prop；暗色主题（`darkTheme`）背景 `#111827`、强调 `#c4b5fd`，色板不变。

## ② 大屏深色双色体系

深空蓝底上只允许两个色相：**青承载数据、紫做强调**，层级靠明度阶梯：

| 角色           | 色值                      | 用途                                    |
| -------------- | ------------------------- | --------------------------------------- |
| 底（径向渐变） | `#10305e → #081428`       | 大屏背景，顶部微亮                      |
| 面板           | `rgba(23, 68, 130, 0.22)` | 卡片底，描边 `rgba(56, 189, 248, 0.24)` |
| 文字           | `#e0f2fe` / `#8fb8d8`     | 主 / 次                                 |
| 数据主         | `#38bdf8`                 | 折线主线、仪表、迷你图                  |
| 强调           | `#a78bfa`                 | 第二系列、堆叠对比                      |

**SKY 明度阶梯**（环图 / 漏斗的层级，靠明度不靠色相）：

`#0c4a6e → #0369a1 → #0ea5e9 → #38bdf8 → #7dd3fc`

**语义色**（红绿只保留涨跌语义）：瀑布图 增 `#38bdf8` / 减 `#fb7185` / 合计 `#818cf8`。

## ③ 3D 组件默认色带（浅底可读）

| 组件      | 色带（低 → 高）                       |
| --------- | ------------------------------------- |
| Bar3D     | `#7c3aed → #c4b5fd`                   |
| Scatter3D | `#7c3aed → #0ea5e9`                   |
| Surface3D | `#38bdf8 → #6366f1 → #a855f7`（三段） |
| Voxel3D   | `#c4b5fd → #7c3aed`（低浅高深）       |

**Scatter3D 类别板**（6 色，浅底饱和）：

`#7c3aed` `#0891b2` `#db2777` `#ea580c` `#16a34a` `#4f46e5`

深色大屏场景请用 `colorRange` 覆盖为亮色带（大屏示例：`#0c4a6e → #38bdf8 → #fde68a` 一类）。

## ④ 装饰组件色（面向深底场景）

| 组件                      | 色值                                                |
| ------------------------- | --------------------------------------------------- |
| ParticleField 粒子 / 连线 | `#38bdf8` / `#0ea5e9`                               |
| HoloRing 环               | `#38bdf8` `#a78bfa` `#22d3ee`（三层可加 `#34d399`） |

装饰组件（ParticleField / HoloRing）面向深色大屏场景——浅底上使用请给容器加深色背景，或整体调高透明度。

## 用法约定

1. **一套页面只用一个色相家族**：青承载数据、紫做强调，红绿只留涨跌语义；
2. **层级靠明度阶梯，不靠换色相**：同族 4~5 档明度（如 SKY_LADDER）足够表达 5 个层级；
3. **换肤走令牌**：`--aura-*` CSS 变量（见主题定制），3D 场景通过 `useScene().readToken` 消费同一套令牌；
4. **3D 深浅底适配**：浅底用本页默认色带，深底大屏传亮色 `colorRange` 覆盖。
