# FunnelChart 漏斗图

漏斗图把一个多阶段流程画成上宽下窄的形状，每一层的宽度对应这一层的量。

## 何时使用

- 转化流程分析（访问 → 加购 → 结算 → 支付）
- 招聘、审批等有明确阶段与流失的流程
- 需要一眼看出「哪一层掉得最狠」

不适合：阶段之间没有先后关系（用[柱状图](/charts/bar-chart)）、需要精确比较数值。

## API

### FunnelChartProps

| 属性                                  | 说明                 | 类型                           | 默认值     |
| ------------------------------------- | -------------------- | ------------------------------ | ---------- |
| data                                  | 数据，按流程顺序排列 | `{ name; value; color? }[]`    | `[]`       |
| label                                 | 标签位置             | `'inside' \| 'right' \| false` | `'inside'` |
| gap                                   | 项间距（像素）       | `number`                       | `4`        |
| theme / palette / tooltip / animation | 同基础图表           | —                              | —          |

## 设计说明

**面积编码是非线性的**

梯形面积 ∝（上宽 + 下宽）× 高 / 2，所以「面积减半」并不等于「数值减半」。漏斗图适合看流失的**位置**，不适合做精确的比例判断。需要精度时请配一张表格或柱状图。

**标签内嵌的宽度门槛**

内嵌标签只在梯形上沿宽度大于 90px、层高大于 26px 时显示。放不下还硬塞，文字会溢出图形，反而更难读。

**数据顺序即流程顺序**

组件不会自动排序。「上宽下窄」的视觉隐喻依赖调用方按流程顺序传数据——如果第二阶段的量比第一阶段还大，那不是 bug，是数据本身在告诉你流程有问题。
