# GaugeChart 仪表盘

仪表盘只回答一个问题：**当前值处在量程的什么位置**。

它不承载多指标比较，也不适合展示趋势——那是[折线图](/charts/line-chart)的事。

## 何时使用

- 看板顶部的核心 KPI（完成率、产能、评分）
- 需要「是否超标」的即时判断（配合分段配色）
- 单个数值的可视化，空间有限

## API

### GaugeChartProps

| 属性                        | 说明                 | 类型                              | 默认值        |
| --------------------------- | -------------------- | --------------------------------- | ------------- |
| value                       | 当前值               | `number`                          | —             |
| min / max                   | 量程                 | `number`                          | `0` / `100`   |
| unit                        | 单位，显示在数值右侧 | `string`                          | `''`          |
| label                       | 数值下方的说明       | `string`                          | —             |
| ranges                      | 分段配色，按上界匹配 | `{ to: number; color: string }[]` | —             |
| thickness                   | 环宽占半径比例       | `number`                          | `0.14`        |
| startAngle / sweepAngle     | 弧起止角度（度）     | `number`                          | `150` / `240` |
| theme / palette / animation | 同基础图表           | —                                 | —             |

## 设计说明

**为什么没有指针？**

指针图形要判断角度，而人眼判断「沿弧长的比例」的精度远高于判断一根细线的夹角。填充弧还顺带表达了进度语义，不需要额外的图例说明。

**为什么是 240° 而不是整圆？**

留出下方 120° 的空缺，既能放标签，也避免了「闭环=100%」的歧义——整圆让人误以为满了会闭合。

**刻度按 10% 均分**

无论量程是多少，刻度始终等分 10 格。这是刻意的：仪表盘用于快速判断位置，不需要读出精确刻度值（精确值在中心）。
