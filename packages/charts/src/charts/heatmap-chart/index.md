# HeatmapChart 热力图

热力图把「行 × 列」的数值映射成颜色深浅，用颜色密度一次呈现几十上百个格子，适合找**热点与空档**。

## 何时使用

- 时间 × 维度的分布（一周各时段的访问量）
- 相关性矩阵、交叉销售矩阵
- 需要在一屏内展示 30 个以上的数值

不适合：需要精确读数（颜色编码精度低于长度/位置，请配合 tooltip 或改用[柱状图](/charts/bar-chart)）、分类少于 5 个。

## API

### HeatmapChartProps

| 属性                        | 说明             | 类型                                                | 默认值       |
| --------------------------- | ---------------- | --------------------------------------------------- | ------------ |
| data                        | 格子数据         | `{ x: string; y: string; value: number \| null }[]` | `[]`         |
| xLabels                     | 显式指定列顺序   | `string[]`                                          | 数据出现顺序 |
| yLabels                     | 显式指定行顺序   | `string[]`                                          | 数据出现顺序 |
| colorRange                  | 色阶两端颜色     | `[string, string]`                                  | 强调色浅→深  |
| showValue                   | 格内数值         | `boolean \| 'auto'`                                 | `'auto'`     |
| cellGap                     | 格子间隙（像素） | `number`                                            | `3`          |
| cellRadius                  | 格子圆角         | `number`                                            | `3`          |
| tooltip / theme / animation | 同基础图表       | —                                                   | —            |

## 设计说明

**`value: null` 与 `value: 0` 必须区分**

缺失表示「没有采集到」，0 表示「采集到了，值是 0」。两者在业务上完全不同，因此缺失格用一个极浅的中性底填充，而不是染成色阶最低色——否则读者会把「空白」误读成「最低」。

**自动决定是否标数值**

格子宽度 ≥ 34px 且高度 ≥ 22px 时才显示数字。放不下就只留颜色，因为挤出图形的文字比没有数字更糟。

**字色随底色反转**

色阶位置 > 0.55（偏深）的格子用白字，其余用深色字。固定字色在渐变底色上必然有一段不可读。

**色阶为什么不用彩虹色**

彩虹色阶（jet）在中间段会产生虚假的「边界」感知——人眼对红绿黄黄绿的亮度变化并不单调，容易把连续数据读成几个离散档位。单色明度渐变是最安全的默认。
