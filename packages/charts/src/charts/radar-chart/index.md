# RadarChart 雷达图

雷达图把 n 个指标沿圆周等分，每个指标的数值映射为「距圆心的距离」，连线成多边形。它编码的不是某个具体数值，而是**形状**——多指标的综合轮廓。

## 何时使用

- 对比 2~~4 个对象在 5~~8 个指标上的整体表现
- 寻找「短板」——轮廓凹陷的方向就是弱项
- 指标之间量纲不同但可以各自归一（如都用 0~100 分）

不适合：需要精确读数（用[柱状图](/charts/bar-chart)）、指标超过 10 个（轮廓会变成噪声）。

## API

### RadarChartProps

| 属性                                           | 说明                                      | 类型                                         | 默认值 |
| ---------------------------------------------- | ----------------------------------------- | -------------------------------------------- | ------ |
| indicators                                     | 指标定义，`max` 为该指标的满分            | `{ name: string; max: number }[]`            | `[]`   |
| series                                         | 数据系列，`values` 与 indicators 一一对应 | `{ key; name?; values: number[]; color? }[]` | `[]`   |
| levels                                         | 同心网格层数                              | `number`                                     | `4`    |
| legend / tooltip / theme / palette / animation | 同基础图表                                | —                                            | —      |

## 设计说明

**为什么 max 必须显式指定？**

如果每个指标各自取数据里的最大值，那么「谁更好」就失去了参照——每个系列都会在某个指标上顶到顶点。指标的量纲与满分是业务语义，不该由图表猜测。

**为什么建议不超过 8 个指标？**

轴越多，相邻轴的夹角越小，读者判断「某个点离圆心多远」的精度越低。超过 8 个指标时，轮廓的主要信息已经变成噪声。

**数值超过 max 的处理**

会被夹紧到网格外沿（最多 1.2 倍）。让点飞出网格会破坏整张图的尺度感，而不夹紧又会导致绘制区域溢出画布。
