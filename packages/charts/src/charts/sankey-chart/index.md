# SankeyChart 桑基图

桑基图把流量画成**带子**：宽度 = 数值，左右位置 = 阶段，带子汇合与分叉 = 流转关系。

## 何时使用

- 流量来源 → 落地 → 转化的全链路
- 预算从总额拆到各部门再拆到具体项
- 能源、物料、资金的多级流向

不适合：线性流程无分叉（用[漏斗图](/charts/funnel-chart)）、只需要看总量占比（用[矩形树图](/charts/treemap-chart)）。

## API

### SankeyChartProps

| 属性                                  | 说明                          | 类型                | 默认值 |
| ------------------------------------- | ----------------------------- | ------------------- | ------ |
| nodes                                 | 节点列表；不传时从 links 推导 | `SankeyNode[]`      | 自动   |
| links                                 | 流向数据                      | `SankeyLinkInput[]` | `[]`   |
| nodeWidth                             | 节点矩形宽度                  | `number`            | `12`   |
| nodeGap                               | 同层节点间隙                  | `number`            | `10`   |
| showValue                             | 末层节点显示流量              | `boolean`           | `true` |
| tooltip / theme / palette / animation | 同基础图表                    | —                   | —      |

## 设计说明

**分层用最长路径，不用 BFS 层号**

BFS 只看「离源点多远」，同一个节点可能被不同源点算出不同层号。最长路径（每层取所有前驱的最大层 + 1）保证任何一条链路都从左往右走，不会出现带子向左回流。

**端口按顺序切分**

一个节点可能进也出多条流量。把它的整个高度按顺序切给各条带子，带宽之和恰好等于节点高度——这样节点与带子的衔接处不会出现错位缝隙。

**含环数据不报错**

真实业务数据里经常有 `A → B → A` 这种回流。拓扑排序遇到环会死循环，这里用「松弛 n 轮后停止」兜底：布局可能不完美，但图能画出来。展示型图表在白屏和「不够准」之间，选后者。

**为什么带宽是半透明的**

带子之间大量重叠，实色会把下层完全遮住。0.26 的不透明度既能看到流向，也能看出交叉关系。
