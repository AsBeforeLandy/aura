# TreeChart 树图

树图只表达**结构**：谁属于谁、有几层、怎么分支。节点大小恒定，不编码数值。

与[矩形树图](/charts/treemap-chart)的分工：矩形树图用面积回答问题「谁占得多」，树图回答「谁挂在哪里」。

## 何时使用

- 组织架构、分类体系
- 目录树、依赖关系
- 决策路径、故障树

不适合：需要比较各分支的量级（用矩形树图）、节点超过 200 个（纵向会挤成一团）。

## API

### TreeChartProps

| 属性                                  | 说明                 | 类型            | 默认值  |
| ------------------------------------- | -------------------- | --------------- | ------- |
| data                                  | 根节点               | `HierarchyNode` | —       |
| nodeSize                              | 节点圆点半径         | `number`        | `4`     |
| showValue                             | 叶子是否显示数值     | `boolean`       | `false` |
| labelSpace                            | 右侧为标签预留的宽度 | `number`        | `96`    |
| tooltip / theme / palette / animation | 同基础图表           | —               | —       |

节点数据结构与[矩形树图](/charts/treemap-chart#hierarchynode)一致。

## 设计说明

**纵向均分 + 父取子均值**

每一行的高度由叶子数决定，父节点的 y 取子节点 y 的均值。这是保证「连线不交叉」的最简做法：只要子节点连续排列，父节点落在它们中间，正交连线必然不交叉。

**正交折线而不是贝塞尔**

层级结构的本质是「折一次弯再横过去」。用贝塞尔曲线会让连线看起来像数据流（那是桑基图的语义），正交折线更准确。

**父节点画成空心圆**

实心 = 数据点，空心 = 结构节点。这个区分让读者一眼看出哪些是叶子（有值）哪些只是分组。

**为什么不支持折叠**

折叠需要维护展开状态、重算布局、处理动画中的布局跳变。当前定位是「结构展示」，需要交互式折叠时请用专业的树组件，而不是把图表组件做成一棵树编辑器。
